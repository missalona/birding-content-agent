# Weekly Content Agent for a Birding Channel

An exercise for an AI implementation course, Lesson 6: AI agents on the Claude platform.

A plan for a Managed Agent that, every week, researches topics, produces 5 Shorts and 1 long video for a YouTube channel about birdwatching, uploads and schedules them, and reports by email.

The client and the channel are examples for the exercise. Identifying details were replaced with generic names.
