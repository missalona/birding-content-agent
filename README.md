# Weekly Content Agent for a Birding Channel

An exercise for an AI implementation course, Lesson 6: AI agents on the Claude platform.

A plan for a Managed Agent that, every week, researches topics, produces 5 Shorts and 1 long video for a YouTube channel about birdwatching, uploads and schedules them, and reports by email.

The client and the channel are examples for the exercise. Identifying details were replaced with generic names.

## Files

| File | What is in it |
|---|---|
| [SPEC.md](SPEC.md) | The detailed plan: how the agent works, which tools it uses, and how its memory is managed |
| [Architecture.md](Architecture.md) | The flow diagrams: what starts the agent, where information comes from, where the results go, and every component of the system |
| [BUILD.md](BUILD.md) | The real build on the Claude Platform: the agent's configuration (model, effort, tools, prompt), the rooms, the memory store, 4 test sessions with their costs, and what the build changed in the plan |
